  {\large\bfseries Predictive risk expansion and bounded tuning regimes}\\[2pt]
  September 16, 2026. Local proof; independent and human review pending
\end{center}

\textbf{Assumptions.} Let $I,J$ be binary with $P(I = 1) = 1/2$, $P(J = 1) = q$,
and $P(I = 1,J = 1) = q(1 + \ell)/2$. Set $x = (I - 1/2,J - q)^\top$ and
$y = x^\top\beta^* + \varepsilon$, with $\E(\varepsilon \mid x) = 0$,
$\E(\varepsilon^2 \mid x) = \sigma^2$. Use known population centering and
scales, a fixed zero intercept, zero initialization, the averaged squared loss,
and $B$ fresh independent samples per SGD update. All errors are on the original
feature scale; test samples are independent. Put $a = 1/4$, $b = q(1 - q)$,
$c = q\ell/2$, $D = \eta P = \diag(u/a,v/b)$. The proposed domain is
\[
  0 < q
    \leq 1/16,\quad |\ell|
    \leq 1,\quad B
    \in \mathbb N,\quad 0
    < u
    \leq 1/4,\quad v
    = u(4b)^{1-2\delta},\quad 0
    \leq \delta
    \leq 1/2,\quad \theta
    = \frac{v}{bB}
    \leq 1.
\]
Here feature divisors are $(a^\delta,b^\delta)$ and $\eta = u a^{2\delta-1}$;
$\delta = 0$ is unscaled U and $\delta = 1/2$ is SD scaling S. Pointwise
comparisons match $M = kB$ observations; tuning sets use a common cap
$kB \leq M$. Each comparison fixes the test law.

\textbf{Approximation.} Write $s_k = (\E e_C^2,\E e_Ce_R,\E e_R^2)^\top$ for
coefficient error $e = \hat\beta - \beta^*$, so $s_{k+1} = Ls_k + \sigma^2g$ is
the exact binary moment recurrence. Remove the rare-error term from the common
update to obtain the triangular moment map $L_0$; retain its first feedback
correction:
\[
  z_{k+1} = L_0z_k + \sigma^2g,\qquad \xi_{k+1}
          = L_0\xi_k + (L - L_0)z_k,\qquad z_0
          = s_0,\quad \xi_0
          = 0.
\]
The maps, scalar geometric sums, and computable error bound $E_{W,k}$ are
specified in \texttt{notes/predictive-claim.md}. For $W = C = \E xx^\top$ or
$W = C_R = \E[xx^\top\mid J=1]$, set $w_W = (W_{CC}/2,W_{CR},W_{RR}/2)^\top$ and
$\widehat R_{W,k} = w_W^\top(z_k + \xi_k)$ and $R_{W,k} = w_W^\top s_k$. Risks
exclude irreducible test noise. The surrogate retains common-to-rare learning
and multiplicative noise; the correction retains effects that can determine a
small aggregate-risk gap.

\textbf{Locally proved bound.} The moment map satisfies
$\rho(|L|) < 1 - v/4 < 1$, establishing mean-square stability. Uniformly on this
domain, for every $k \geq 0$, signal, and $\sigma^2 \geq 0$,
\[
  |R_{W,k} - \widehat R_{W,k}|
  \leq E_{W,k}
  \leq Kq^2\!\left[ \|\beta^*\|_2^2 e^{-kv/4} + \sigma^2\left( \frac{u}{B} + \theta \right) \right].
\]
This holds with $K = 104/3$; sharper constants by objective and error component
are proved in the
\href{../notes/predictive-claim-feasibility.md}{feasibility note}. Weighted
triangular resolvents bound each accumulated feedback insertion by $O(q)$. For
an S-minus-U contrast $\widehat\Delta = \widehat F + \sigma^2\widehat N$, the
inequalities $\widehat\Delta \pm (E_S + E_U)$ give sufficient risk orderings and
bracket a noise threshold when its denominator has a certified positive sign.
For any declared rate/stopping set $\mathcal A$ with $kB \leq M$,
$\inf_{\mathcal A}(\widehat R - E) \leq \inf_{\mathcal A}R \leq \inf_{\mathcal A}(\widehat R + E)$;
overlapping intervals remain unresolved.

\textbf{Prediction and scope.} At $kB = M$, rare learning exposure is
$kv = Mb\theta$, whereas its direct stationary coefficient-noise term is
$\sigma^2\theta/[2 - v - \theta(1 - 4b)]$. Thus faster learning can win early
and lose after bias decays; reducing the rate as $M$ grows can remove that late
penalty. Matching $v$ leaves common learning and dependence effects, so neither
path equivalence nor universal tuned superiority follows. The
\href{../notes/predictive-regime.md}{predictive comparison} now covers
independent features, $\sigma^2 > 0$, $B = 1$, $0 < q \leq 10^{-4}$, and
$1 \leq Mb \leq 4$. Over all U/S rates in the domain and all $k \leq M$, SD's
oracle rare risk is at least $0.007\sigma^2$ lower when
$(\beta_R^*)^2 = \sigma^2$ and $(\beta_C^*)^2 \leq \sigma^2/100$. Unscaled wins
by at least $0.005\sigma^2$ under the swapped signal conditions. A
\href{../notes/predictive-theorem.md}{self-contained theorem} now gives a
shorter direct proof and a separate rational certificate for these same
guarantees. They concern population oracles, not validation selectors.

not remove a normalization-risk separation. The source assessment identifies
this precise addition but does not settle publication-level novelty. Local
mathematical completion and the choice of a central contribution are separate
